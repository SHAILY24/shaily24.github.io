# Portfolio Website

Personal portfolio website showcasing projects and experience across data engineering, full-stack development, and machine learning.

## Features

- Responsive design optimized for all devices
- Interactive project showcase with live demos
- Timeline view of professional experience
- Skills visualization
- Smooth animations and transitions
- Fast loading with vanilla JS (no framework overhead)

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript
- GitHub Pages hosting

## Local Development

1. Clone the repository
```bash
git clone https://github.com/SHAILY24/shaily-portfolio.git
cd shaily-portfolio
```

2. Open index.html in your browser or use a local server
```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.

Live at: [shaily24.github.io/shaily-portfolio](https://shaily24.github.io/shaily-portfolio)
